# sound

Cross-platform sound playback for Dart and Flutter - **no system dependencies**
to install. Pure Dart (works in CLI tools); native audio is reached over FFI.

For Flutter apps, see the `sound_flutter` package, which builds the native
library for you (via cargokit) and registers the right backend automatically.

The only build-time requirement beyond Dart/Flutter is Rust - and eventually
not even that, once precompiled binaries are distributed.
